# Heritage Hub

Интерактивная карта достопримечательностей Гомельской области. Сайт для просмотра объектов, часов работы и построения маршрута. Администратор добавляет объекты через отдельную страницу.

## Запуск через Docker

В папке проекта:

```bash
docker compose up --build
```

- Сайт: http://localhost:8080
- Админка: http://localhost:8080/desk
- Логин и пароль берутся из `server/.env`: `ADMIN_LOGIN` и `ADMIN_PASSWORD`

Docker читает тот же `server/.env`. Адрес базы внутри контейнера задаётся отдельно и не берётся из файла. После смены пароля перезапустите контейнер `api`: при старте сервер обновляет пароль администратора из окружения.

Цвета собраны в `client/src/styles/variables.css`. Меняется группа `--color-*`, и светлая тема перекрашивается целиком.

## Как устроен код

Сервер, `server/src`:

- `index.ts` — подключение к MongoDB, начальное наполнение и запуск
- `app.ts` — Express, CORS и JSON
- `models` — Администратор, Категория, Достопримечательность, Фотография, Отзыв, Сообщение
- `controllers` — вход, каталог, отзывы, чат, маршрут для Яндекс Карт
- `seed/catalog.ts` — стартовые объекты области

Клиент, `client/src/components`:

- `Header`, `MobileMenu`, `HeroSection` — шапка, меню из трёх полос, первый экран
- `AttractionCatalog`, `MapSection`, `RouteBuilder` — список, карта и маршрут
- `ChatWidget` — форма обратной связи в виде чата
- `AdminLogin`, `AdminObjectForm`, `AdminMessageDesk` — админка

Координаты в базе хранятся как GeoJSON Point: `[долгота, широта]`. На карте порядок обратный: `[широта, долгота]`.

Первый клик по метке показывает рейтинг и время работы. Второй клик по той же метке открывает страницу объекта. «Построить маршрут» рисует линию и открывает Яндекс Карты.

## Запуск из IDE

В корне проекта одна команда `npm run dev`. Она сама поднимает MongoDB в Docker, затем сервер и сайт.

- Сайт: http://localhost:5173
- Админка: http://localhost:5173/desk
- Логин и пароль — в `server/.env`, этот файл в репозиторий не входит

Перед первым запуском нужен открытый Docker Desktop. Если сервер уже слушает порт 4000, повторный запуск его не сбивает.

База: `mongodb://127.0.0.1:27017/heritage`. В MongoDB Compass это тот же адрес, база `heritage`. Коллекции: `attractions`, `categories`, `reviews`, `messages`, `admins`.
